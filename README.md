One line, at most 200 characters, roasting a smart fridge — its app, firmware updates, camera, ice maker, and opinions about your milk. Written for make.fun's "Fridge Roast: One Line, Biggest Laugh" bounty.

## Run it

```sh
node main.ts
```

This writes the roast line to `/output/entry.txt`.
